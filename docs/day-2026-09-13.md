## ⓪ 先修一个打字错误 · 1 分钟

`week01/attention_blank.py` **第 72 行**：

```python
scores = (Q @ K.transpose(-1.-2))/math.sqrt(d_k)     # ✗ 现在是这个
scores = (Q @ K.transpose(-1, -2))/math.sqrt(d_k)    # ✓ 应该是这个
```

**`-1.-2` 中间是「点」不是「逗号」。** 后果：

| 写法 | Python 看到什么 | 结果 |
|---|---|---|
| `-1.-2` | 一个浮点数 `-3.0`（`-1.` 减去 `2`） | `TypeError: transpose(): argument 'dim0' must be int, not float` |
| `-1, -2` | 两个整数参数 | 正常 |

现在跑出来是 **4 通过 / 5 待填**（报 TypeError），5 项失败全部源于这一行。

**改一个字符，立刻 9/9。**

- [ ] 改掉这一行
- [ ] `python attention_blank.py` 确认 9/9

> **顺带记一条经验**：Python 里 `-1.-2` 是合法的**数值**表达式，不会报语法错误。
> 这类错误最难查——因为报错信息指向的是程序后面很远的地方（`transpose` 的参数类型），
> 而不是这个点本身。**改代码后如果突然报"类型不对"，先怀疑是标点打错了。**
