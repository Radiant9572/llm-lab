## 内容来源

```powershell
E:\Anaconda\envs\llm\python.exe E:\llm-lab\common\today.py
```

`today.py` 从两处取数据：

- `E:\llm-lab\PLAN_12W.md` —— 12 周计划的当周任务与验收标准
- `E:\llm-lab\leetcode\SCHEDULE.md` —— 当天的力扣题号

支持 `--date YYYY-MM-DD` 预演任意一天，`--plain` 去掉框线。

## 落地规则（重要）

1. **只追加，不覆盖。** 文档从「2026-09-26 计划启动前」开始往下累积，
   最新的一天在末尾 —— 这样历史勾选记录会保留下来，能看到自己这周真做了什么。
2. **覆盖是被明确排除的**：资料库对「整篇正文全量替换」会要求用户二次确认，
   而定时任务运行时没有人在场，一确认就会卡住。所以自动任务永远走追加。
3. **`today.py` 报错就跳过本次**，不要往文档里写空段落。

## 每天追加的段落格式

```markdown
## 2026-09-28（周一）· W1 / 12

- [ ] 项目 · <当周任务>
- [ ] 刷题 · <题号 题名>
- [ ] 日报 journal/2026-09-28.md
- [ ] 提交推送
```

周日额外加一行：`- [ ] 更新 README 进度表 + 检查这周 commit 有没有断档`

## 为什么不用别的方式（避免以后重复论证）

- **直连手机自带待办**：做不到。手机待办是本地加密存储 + 厂商云账号，不开放给第三方程序。
- **邮件**：可行（本机有邮箱连接器），但邮件不算真正的待办，只能标已读。
- **腾讯文档**：本会话的连接器处于停用状态，未启用。
- **资料库文档**：无需额外授权，手机端打开即用，`Todo` 块可点勾 —— 综合摩擦最小。
