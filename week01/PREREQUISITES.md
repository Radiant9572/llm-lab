## 0. 先定位：你到底卡在哪一层？

"写不出来"有三种完全不同的原因，解法也完全不同。先自己判断一下：

| 层级 | 典型症状 | 如果你的情况 |
|---|---|---|
| **L1 数学层** | 不知道 softmax 是什么、不懂为什么要除以 sqrt(d_k)、不明白掩码在数学上做什么 | 概率论/线代基础。**你大概率不缺这一层** —— 数学是你的主场 |
| **L2 形状层** | 知道数学上要干什么，但不知道怎么把它变成张量运算。比如"我知道要让 Q 和 K 转置相乘，但写成代码就不知道怎么下手" | **最常见的卡点，几乎所有人第一次都卡这里** |
| **L3 API 层** | 知道要写矩阵乘，但不确定 `transpose(-2, -1)` 是什么意思、`@` 支不支持批量、`masked_fill` 参数怎么传 | 第二常见。纯查文档就能解决 |

**判断方法**：试着用中文说清楚这三件事——

1. 注意力机制整体在干什么？
2. Q 和 K 做点积，得到的东西代表什么？
3. 因果掩码把哪一半挡住了？

**如果第 1 条就说不清 → 你在 L1，请先读 [`ATTENTION_CONCEPTS.md`](ATTENTION_CONCEPTS.md)。**
那份文档用四张图讲清了点积=相似度、Q/K/V 的来源、完整四步流程、因果掩码。**读完再回来填代码，效率差十倍。**

- 说得出来但写不出代码 → **L2 或 L3**，继续往下看
- 都能说出来 → 直接去填 `attention.py`

先明确一点：**上面三种情况都不需要你去读深度学习教材。** 下面是 L2 / L3 需要补的东西。

## 1. 你真正需要补的（按优先级，全部加起来约 6 小时）

### 1.1 PyTorch 张量操作手感（最高优先级，约 2 小时）

不是学完整个 PyTorch。只需要下面这几类操作熟练到不用查：

```python
import torch

# ---------- 形状 ----------
x = torch.randn(2, 3, 4)
x.shape                    # torch.Size([2, 3, 4])
x.transpose(-2, -1)        # 交换最后两维 → (2, 4, 3)
x.reshape(6, 4)            # 重排成 (6, 4)，元素总数必须不变
x.unsqueeze(0)             # 在第 0 维前面插一个长度 1 的维度 → (1, 2, 3, 4)
x.permute(2, 0, 1)         # 按指定顺序重排所有维度

# ---------- 矩阵乘（本练习的核心）----------
A = torch.randn(2, 3, 5)
B = torch.randn(2, 5, 4)
A @ B                      # → (2, 3, 4)
# 规则：只对**最后两维**做矩阵乘，前面的维度必须相同（或可广播）
# 所以 Q @ K.transpose(-2, -1) 里，transpose 的作用就是把 d_k 换到最后，
# 让两个矩阵的"内维"对上。

# ---------- dim 参数（最容易出错的地方）----------
s = torch.tensor([[1., 2., 3.],
                  [4., 5., 6.]])
s.sum(dim=-1)                    # → tensor([ 6., 15.])   沿最后一维求和，该维消失
s.sum(dim=-1, keepdim=True)      # → tensor([[ 6.], [15.]]) 保留成长度 1，才能广播

s.max(dim=-1)                    # ⚠️ 返回的是个 namedtuple，不是张量！
s.max(dim=-1).values             # 取最大值
s.max(dim=-1).indices            # 取最大值的位置
s.max(dim=-1, keepdim=True).values   # 值 + 保留维度

# ---------- 掩码 ----------
mask = torch.tensor([[True, False],
                     [True, True]])
s.masked_fill(~mask, float("-inf"))   # ~ 是按位取反，把 True/False 翻过来
torch.tril(torch.ones(4, 4))          # 下三角（含对角线）—— 造因果掩码可以用它

# ---------- 广播 ----------
torch.randn(4, 1) + torch.randn(1, 5)   # → (4, 5)
```

**⚠️ 上面第 4 类里 `s.max(dim=-1)` 返回 namedtuple 这件事，是初学者最常踩的坑。** 我写 TODO 1 的提示时用了 `.values`，就是因为这个。

**去哪学（精确到页面）**
- PyTorch 官网 → Learn the Basics → **Tensors** 一节（约 30 分钟，够用）
- PyTorch 官网 → **Broadcasting semantics** 那一页（很短，必读）
- 不要去看 "60 Minute Blitz" 的后半部分（训练神经网络那些），现在用不上

**怎么学**：所有代码在本地敲一遍，**每敲一段就 `print` 一次 shape**。这一步不能省，形状直觉只能靠手打出来。

### 1.2 广播规则（约 30 分钟）

就三条，但必须记牢，否则形状对不上时你只能瞎试：

1. 两个张量从**最右边**开始逐维对齐，短的左边补 1
2. 同一位置上：尺寸相等 → 通过；有一个是 1 → 广播成另一个的尺寸
3. 两个都不满足 → 报错

这就是为什么我反复强调 `keepdim=True`：`x.max(dim=-1)` 得到形状 `(L,)`，而 `x` 是 `(L, S)` —— 两者右对齐后是 `(S,)` vs `(L, S)`，对不上会报错。加上 `keepdim=True` 得到 `(L, 1)`，右对齐后就能广播成 `(L, S)`。

**建议**：读完规则后回到 `attention.py`，把每个 TODO 里涉及形状的中间变量都手写一遍它的形状。写出来之后，代码基本就自己浮现了。

### 1.4 L2 专用：形状推演法（**最重要的方法**）

如果你确诊在 L2，上面那些 API 背得再熟也没用，因为你缺的是**方法**而不是知识。

**错误做法**：脑子里想"Q 和 K 要相乘"，然后开始试各种写法，看报错猜。
**正确做法**：**先把形状写下来，再写代码。** 每次都是同样三步：

1. **写出输入和目标的形状**
2. **判断操作类型**：改变形状？矩阵乘？逐元素运算？
3. **矩阵乘只看最后两维能不能对上**

以注意力为例，把表填完，代码几乎是逐行翻译：

```
输入：Q (B, L, d_k)    K (B, S, d_k)    V (B, S, d_v)
目标：out (B, L, d_v)

步骤        数学          形状推演                                  对应操作
─────────────────────────────────────────────────────────────────────────────
① 转置 K    Kᵀ            (B, S, d_k) → (B, d_k, S)                 transpose(-2,-1)
② 打分      Q·Kᵀ          (B,L,d_k) @ (B,d_k,S) → (B, L, S)         @
③ 缩放      / √d_k        (B, L, S) 不变                             /
④ 掩码      masked_fill   (B, L, S) 不变                             masked_fill
⑤ 归一化    softmax(-1)   (B, L, S) 不变，每行和 = 1                  softmax
⑥ 加权求和  attn·V        (B,L,S) @ (B,S,d_v) → (B, L, d_v) ✓        @
```

**看懂 ①→② 就懂了全部**：矩阵乘只作用在最后两维，`(L, d_k) @ (d_k, S) = (L, S)`，前面的 B 原样保留。所以要让 `d_k` 对上，只需把 K 的最后两维换位置。

**配套练习**：`shape_drill.py`（10 个填空，专门练"看到形状变化就知道用哪个操作"这个条件反射）。

**习惯建议**：以后写任何涉及张量的代码，先在注释里把每个中间变量的形状写出来再动手。这个习惯坚持两周，L2 就永久消失了。

```python
def stable_softmax(x, dim=-1):
    x_max = x.max(dim=dim, keepdim=True).values
    e = torch.exp(x - x_max)
    return e / e.sum(dim=dim, keepdim=True)


def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)

    scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)

    if mask is not None:
        scores = scores.masked_fill(~mask, float("-inf"))

    attn = stable_softmax(scores, dim=-1)

    out = attn @ V
    return out


def make_causal_mask(seq_len):
    row = torch.arange(seq_len).view(-1, 1)
    col = torch.arange(seq_len).view(1, -1)
    return col <= row
```
