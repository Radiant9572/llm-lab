# 学习日志

一天一个文件，命名 `YYYY-MM-DD.md`。

**规则只有一条：写短。** 每天 3 分钟，超过 10 行说明你在写作文——那份时间该拿去做实验。

重的东西（实验数据、消融结果、归因）不写在这里，写进对应的 `weekNN/EXPERIMENTS.md`。

---

## 模板

```markdown
# YYYY-MM-DD（周X）

**今日投入**：__ 小时

## 做了什么
- 

## 卡点 / 报错
- 

## 结论
- 

## 明天
- 
```

## 各栏怎么写

| 栏位 | 写什么 | 不要写什么 |
|---|---|---|
| 做了什么 | 具体到能复现的动作。"实现因果掩码并通过测试" | "学习了注意力机制" |
| 卡点 | 报错原文 + 你怀疑的原因 + 最后怎么解的 | "遇到一些困难" |
| 结论 | 一句能被证伪的话。"d_k 越大未缩放 softmax 越饱和" | "很有收获" |
| 明天 | 一件具体的事 | "继续努力" |

**"卡点"这一栏最值钱。** 三个月后你回头看，最有用的不是"我做了什么"，而是"我踩过哪些坑"。面试被追问细节时，这些是你的弹药。
